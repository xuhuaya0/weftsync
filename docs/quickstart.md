# 最简单的用法

三件事：**启动 → 建一条配置 → 比较再同步**。全部在浏览器界面里做，不用手写配置文件。

---

## 一、启动

双击 `dist\weftsync-windows-amd64.exe`。

- 窗口闪一下就没是正常的，它转到后台了
- 浏览器会自动打开界面
- 右下角托盘图标右键可以「打开控制台 / 立即运行全部 / 退出」

再双击一次 = 把界面重新调出来，不会启动第二份。

---

## 二、建配置

点左侧 **新建**，然后：

1. **本机** — 填要同步的本地目录
2. **云端** — 填目标目录
3. 点 **另存为**，起个名字（比如 `work`）

前端两栏就是"从哪同步到哪"，只有这两个框是必须填的。

---

## 三、比较 → 同步

1. 点顶栏 **比较** —— 只读两侧，不写入任何东西，下面会列出要增/改/删的文件
2. 看一眼那张表
3. 点 **同步** —— 这时才真正动文件

有删除项时会先弹确认框，把所有要删的路径列出来。

---

这就完了。下面是可选的。

## 想先练手，别碰真数据

云端栏填 `:local:` 开头的本地路径，纯本地跑，不联网不要凭据：

```
本机： D:\data\src
云端： :local:D:\data\dst
```

## 想定时跑

先保存配置，再打开右侧 **配置表单** 页签，选这条作业，在「调度」里设模式：

- `interval` + 间隔 `1h` — 每小时
- `daily_time` + `02:30` — 每天两点半
- `none` — 只手动（默认）

## 想连飞书

**全局设置与凭据** → **+ 新增云盘连接** → 类型选 `feishu` → 填三项：

- `app_id`、`app_secret` — 飞书开放平台的应用凭证
- `root_token` — 目标文件夹，整条分享链接粘进去也行

填完点 **测试连接**，通过后目录对里就能写 `连接名:子目录`。

---

配置文件就是普通 `.toml`，字段说明见 [`job-file.md`](job-file.md)。
