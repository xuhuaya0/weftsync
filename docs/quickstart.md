# 快速上手

三个步骤：启动 → 新建配置 → 比较并同步。全部通过浏览器界面完成，无需手写配置文件。

---

## 一、启动

### Windows

双击 `dist\weftsync-windows-amd64.exe`。

- 控制台窗口在服务就绪后自动隐藏，进程转至后台运行
- 默认浏览器自动打开控制台
- 托盘图标右键提供「打开控制台 / 立即运行全部 / 退出」

重复双击不会启动第二个实例，只会重新打开控制台。

### Linux

```bash
chmod +x weftsync-linux-amd64
./weftsync-linux-amd64
```

无参数启动等同于 Windows 双击：服务就绪后通过 `xdg-open` 打开控制台。若需在终端查看日志，或指定配置文件，改用显式命令：

```bash
./weftsync-linux-amd64 daemon job.toml
```

需要开机自启时，在「全局设置与凭据」中启用「开机自启」，会写入 `~/.config/autostart/weftsync.desktop`，并要求存在图形会话。

---

## 二、新建配置

点击左侧 **新建**，然后：

1. **本机** — 填写待同步的本地目录
2. **云端** — 填写目标目录
3. 点击 **另存为**，指定配置名（例如 `work`）

这两栏是唯一必填项。保存后配置以 `.toml` 文件形式落盘，可纳入版本管理。

不需要的配置可在左侧 **删除** 中移除：只移除条目，或连同文件一并删除，由对话框中的勾选项决定。

---

## 三、比较与同步

1. 点击顶栏 **比较** — 仅读取两侧，不写入任何一侧，下方列出待新增、更新、删除的文件
2. 核对结果
3. 点击 **同步** — 此时才实际写入

存在删除项时，会先弹出确认框并列出全部待删路径。

---

## 定时运行

配置保存后，打开右侧 **配置表单** 页签，选择对应作业，在「调度」中设置：

| 模式 | 参数 | 说明 |
|---|---|---|
| `interval` | 间隔 `1h` | 按固定间隔运行 |
| `daily_time` | 每日时刻 `02:30` | 每天指定时刻运行 |
| `none` | — | 仅手动运行（默认） |

---

## 添加飞书连接

打开 **全局设置与凭据** → **+ 新增云盘连接**，类型选择 `feishu`，填写三项：

| 字段 | 来源 |
|---|---|
| `app_id` | 飞书开放平台 → 应用 → 凭证与基础信息 |
| `app_secret` | 同上，保存后加密存储 |
| `root_token` | 目标文件夹分享链接，可直接粘贴完整 URL |

填写后点击 **测试连接**，通过后在目录对中引用 `连接名:子目录` 即可。

飞书后端需要同步快照文件（其目录列表不返回文件大小，缺少快照将导致每次全量重传）。快照路径按目录对自动生成，无需手工配置。

---

配置文件为普通 `.toml`，字段说明见 [`job-file.md`](job-file.md)。
