远程凭据 写在 rclone 配置文件里
密钥不会回显——这里只显示是否已设置以及字符长度 （长度能帮忙发现多打进去的空格或换行）。保存时密钥以 rclone 的模糊形式写入配置文件， 在 Linux / macOS 上文件权限会被收紧到 0600。
字段留空 = 不修改；要清除已存的值，勾选右侧的「清除」。
威胁模型要说清楚：rclone 的「模糊」（obscure）是 混淆，不是加密 —— 它用一个固定算法把明文转成不可读的串， 但没有密钥保护。换句话说：能读到这个配置文件的人，就能还原出 app_secret。 这里能保证的是「文件不给别人读」（权限 0600），以及「密钥不出现在网页上」。 如果需要防止本地磁盘被读，请用操作系统级的加密（BitLocker / LUKS / FileVault）。
