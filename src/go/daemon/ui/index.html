目录拆分
飞书单层最多 1500 个直接子项，超过会报错；本工具在 1400 就拦下，留出余量。拆分是会移动你本地文件的操作： 先移动本地（可秒级回滚），再移动云端（受限速影响较慢），最后校验两侧。
定时任务永不自动拆分，只在同步前拦下并提示。拆分前会写一份账本，可用「撤销」移回原位。
